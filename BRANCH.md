# `pr/browser`

One part of the topic repo p1ngb4ck/esphome-browser. The whole topic, with its description, is the branch `main`.

Change of this branch: `browser`: a browser served over VNC / SPICE, opened through remote_desktop (`browser.open` / `close` / `is_open`)

Based on these branches, whose changes it holds and builds on:

- `pr/remote-desktop` of p1ngb4ck/esphome-remote-desktop: `remote_desktop`: VNC (RFB, Tight JPEG through the hardware decoder) and SPICE (MJPEG streams, JPEG images through the hardware decoder) on a page canvas of the video output; keys / mouse / touches, cursor, SPICE sound, USB redirection (usbredir; USB/IP with VNC), saved connections, probing (`protocol: auto`), close gestures
